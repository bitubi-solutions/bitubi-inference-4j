# GitHub-hosted A/B runs (2026-11-02)

Workflow `.github/workflows/perf.yaml` (manual): both commits are built on the same runner and their
`PerfBaselineTest` runs alternate, 5 rounds per side, Panama backend, Qwen2.5-0.5B-Instruct-JQ4. Values are tok/s:
median and [min-max]. Shared runners are noisy too, so read the ranges, not only the medians.

None of the runners reported AVX-512 (`NATIVE_ISAS [avx2]` on Linux, Windows and macOS Intel), so the AVX-512 native
variant is still not executed anywhere. macOS ARM jobs were cancelled by GitHub ("not acquired by Runner ...
capacity constraints") in both runs.

## Varargs-free tensor accessors (`4b9b060` before, `d5504cf` after), run 41483411104

| Runner | Prefill before | Prefill after | Decode before | Decode after |
|---|---|---|---|---|
| ubuntu-latest | 23.69 [23.56-23.96] | 23.81 [23.69-23.94] | 13.99 [13.78-14.53] | 13.95 [13.78-14.87] |
| windows-latest | 18.52 [16.12-18.55] | 18.73 [18.53-18.75] | 12.17 [10.78-12.28] | 12.39 [12.36-12.44] |
| macos-15-intel | 16.66 [12.92-16.79] | 17.07 [16.71-17.66] | 8.93 [7.66-9.09] | 9.01 [8.91-9.19] |

Reading: 0 to 2.5% faster, no regression. Only Windows decode separates cleanly (+1.8%, the ranges do not overlap).
The change is kept as a refactor, not as an optimization.

each other.
